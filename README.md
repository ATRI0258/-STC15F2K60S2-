# 基于STC15F2K60S2的自适应红外感应台灯

> 单片机原理及应用课程设计 | 独立完成

## 项目简介

本项目基于STC15F2K60S2单片机，设计并实现了一款自适应红外感应台灯。系统通过光敏电阻实时检测环境光照强度，结合人体红外传感器（PIR）检测人体活动，实现**人来灯亮、人走灯灭**的自动控制，并能根据环境亮度自动调节灯光亮度（PWM调光）。具备LCD1602液晶屏实时显示当前光照强度、PWM占空比等工作状态。

## 功能特性

- **光敏自动调光**：通过光敏电阻检测环境光照，自动调节PWM占空比控制灯光亮度
- **人体红外感应**：HC-SR501检测人体活动，有人靠近时开灯，人离开后延时熄灭
- **ADC数据滤波**：自定义滑动平均滤波算法，解决ADC采样值波动大的问题
- **LCD状态显示**：LCD1602实时显示光照强度、PWM占空比、人体感应状态
- **手动/自动模式切换**：按键切换手动控制和自动控制模式

## 硬件方案

| 器件 | 型号 | 作用 |

### ADC滑动平均滤波算法

光敏电阻采集的ADC值存在较大波动，直接使用会导致灯光闪烁。本项目实现了一种**带波动检测的滑动平均滤波算法**：

1. 每10ms读取一次ADC值，存入10元素的环形队列
2. 计算10个值中的最大值和最小值，得到波动范围（max - min）
3. 若波动范围 ≤ 16，认为数据稳定，取10个值的平均值作为有效输出
4. 若波动范围 > 16，认为存在干扰，丢弃本次结果，保留上一次有效值

```
// 伪代码
uint16_t adc_filter(void)
{
    uint16_t buf[10];
    uint16_t max_val, min_val;
    uint16_t sum = 0;

    for (i = 0; i < 10; i++)
        buf[i] = read_adc();

    max_val = min_val = buf[0];
    for (i = 0; i < 10; i++) {
        if (buf[i] > max_val) max_val = buf[i];
        if (buf[i] < min_val) min_val = buf[i];
        sum += buf[i];
    }

    if ((max_val - min_val) <= 16)
        return sum / 10;       // 数据稳定，取平均
    else
        return last_valid_val; // 波动过大，保留上次有效值
}
```

### PWM调光实现

利用STC15的定时器中断，软件生成PWM波。通过改变高电平时间占周期的比例（占空比）来控制灯光亮度：

- 环境越暗 → ADC值越大 → PWM占空比越高 → 灯越亮
- 环境越亮 → ADC值越小 → PWM占空比越低 → 灯越暗

### 调试踩坑记录

**问题1：ADC采集数据波动大，LCD显示不稳定**
- 原因：光敏电阻输出受环境光抖动和ADC本身的量化噪声影响
- 解决：实现上述滑动平均滤波算法，波动范围≤16才取平均值

**问题2：继电器驱动电机时LCD乱码**
- 原因：电机功率过大，通断瞬间产生电磁干扰（EMI），耦合到LCD数据线导致显示异常
- 解决：更换小功率电机，降低干扰强度。（更优方案是使用电机驱动芯片隔离，但因PCB已打板无法改版）
